מחשבון הזכויות - קהילת זכויות נשואים בצה"ל
=========================================

התיקייה הזו היא אתר שלם. אין צורך בהתחברות כדי להשתמש בו, וכל הקבצים בו.

העלאה לאינטרנט (בחינם, בלי התקנות), הדרך הפשוטה ביותר:
1. היכנסו ל-https://app.netlify.com/drop
2. גררו לשם את כל התיקייה (לא את קובץ ה-ZIP, אלא את התיקייה אחרי חילוץ).
3. תוך כמה שניות מקבלים כתובת כמו https://random-name.netlify.app
4. בהגדרות האתר (Site configuration > Change site name) בחרו שם קצר, למשל
   tash-plus. הכתובת תהיה https://tash-plus.netlify.app

הלוגו בתצוגה המקדימה בוואטסאפ:
5. פתחו את index.html בעורך טקסט (למשל פנקס רשימות).
6. חפשו את השורה שמכילה YOUR-DOMAIN והחליפו את YOUR-DOMAIN בכתובת האתר
   (בלי https://), כך:
   <meta property="og:image" content="https://tash-plus.netlify.app/og-image.png">
7. העלו שוב את התיקייה לאותו אתר (בלשונית Deploys גוררים אותה פעם נוספת).
8. וואטסאפ שומר תצוגות מקדימות ישנות. כדי לראות את החדשה, שלחו קישור
   שלא נשלח קודם, למשל עם ?v=2 בסוף.

מה בתיקייה:
- index.html          האפליקציה כולה
- docs/               המסמכים והטבלאות (מסך "מידע נוסף")
- og-image.png        התמונה שמופיעה בתצוגה המקדימה בוואטסאפ
- favicon.png, apple-touch-icon.png   אייקון הלשונית והמסך הראשי בטלפון

עדכון תקרות וסכומים: בראש קטע הסקריפט ב-index.html יש אובייקט בשם C
עם כל הסכומים (תקרה, מדרגות, שכר דירה ועוד).
